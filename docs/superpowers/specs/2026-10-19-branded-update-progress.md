# 简约品牌更新窗口

用户已选择并批准简约品牌进度窗口。继续在更新功能隔离分支中实施，无需再次确认设计或部署。

窗口约 480×330，品牌图标、细进度条和真实安装阶段，浅色/深色、紫色/金色沿用客户端 token。已有客户端未传递外观时采用系统配色。新客户端安装请求携带当前外观。运行过程不显示传统 NSIS 页或 PowerShell 控制台，且不增加任何运行时。复用 Windows PowerShell 自带 WPF。

NSIS 仅静默解包和启动 launcher.ps1；launcher 运行单一 worker update.ps1，读取 worker 原子 JSON 进度。CHECK 直接静默执行 worker，不创建 GUI。worker 仍拥有校验、互斥锁、进程等待、覆盖事务、恢复、健康确认和回滚。阶段不可计量时动画，文件校验/覆盖按真实完成数量显示阶段百分比，不声称为整个更新进度。

写入开始后不能关闭或取消。窗口可拖动和最小化。成功且新版启动健康通过后自动关闭。失败保留简短中文提示，提供重试、查看日志、关闭。GUI 模式失败不立即重启旧版，重试可直接重新运行同一 worker；关闭时仅当回滚安全且原客户端身份验证通过才启动旧版。worker 意外退出必须显示失败，不把遗留进度当成功。GUI 加载失败在安装写入前终止并告知日志，不静默退出主程序后失联。

验收：进度协议与文件锁测试、CHECK 无窗口、实际交互桌面浅/深色截图、失败重试及日志入口、真实 1.1.1→RC 覆盖/重启/会话配置保留，两个签名包上传不可变 r5 URL 后更新 feed/官网。
