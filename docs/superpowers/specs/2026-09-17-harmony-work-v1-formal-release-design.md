# Harmony Work v1.0.0 正式版体验重构设计

**状态：** 已确认，进入实现计划前审查

**目标：** 以 Harmony Work 作为第一个正式发布版本，重组高频导航、集中设置与 IM 连接、接入官网工作空间账户数据，并将素材库变成可筛选、可预览的业务内容库。

**范围边界：** 产品名称保持 Harmony Work；对话中的 Agent 自我名称仍为“小亨”。不移除既有 Skill 来源或高级 IM 配置；不在桌面端存储中转站管理员凭据；不将构建缓存、审计材料或浏览器原型纳入版本提交。

## 已确认的产品决定

1. 左侧导航采用“工作优先”结构。
   - 工作：新对话、Harvis 创作、素材库、市场 · 技能。
   - 协作（可展开）：团队、成员、专家、定时任务、记忆。
   - 系统：设置。
   - 工具、日志与头像菜单的调试入口均移至设置内，不再作为独立一级页面。
2. 市场只保留 Skill 的下载、安装、启用、管理和诊断，不再展示专家或团队的顶部标签页。
3. IM 主渠道是企业微信和个人微信。其他既有渠道保留其配置与运行兼容性，但转移至设置内的“高级集成”折叠区。
4. 个人账户页面取代当前头像菜单跳转营销工作台的行为，复用官网工作空间的真实账户接口。
5. 素材库默认只显示业务可用内容；媒体服务器的索引辅助文件不显示；工程源文件由独立格式组显示。

## 信息架构

### 左侧导航与页面路由

`App.tsx` 将取消 `marketTab` 对专家和团队的重定向逻辑。市场路由只渲染 `Skills`，并保留当前用户从聊天输入框“安装技能”的跳转入口。

协作组使用独立的 `collaborationExpanded` 持久化状态。团队继续使用 `Pond`，成员和专家继续使用 `School` 的既有子页；定时任务复用 `Scheduler`，记忆复用 `Memory`。这些模块不再因市场页面卸载而重置状态。

设置成为系统类页面的唯一入口，携带可链接的二级 section 标识：

| 二级菜单 | 承载内容 |
| --- | --- |
| 账户与云端 | 账户概览入口、云端配置同步、登录与退出 |
| 模型与 API | 提供商、模型、API Key、视觉模型 |
| 渠道与连接 | 企业微信、个人微信、高级集成 |
| 工作区与安全 | 工作区、外部文件访问、确认策略、SSH |
| Agent 与技能 | Agent 行为、Skill 偏好、内置工具开关 |
| 外观与交互 | 主题、语言、字体缩放、流式输出 |
| 系统与诊断 | 运行环境、工具、日志、调试、关于 |

原有 `Tools`、`AuditLog` 和 `DebugPanel` 以嵌入 section 的形式保留功能，不删除其业务组件。旧导航调用映射到对应 section，避免存量深链或 Agent 导航失效。

### Skill 市场

市场页采用三个固定视图：

1. **已安装**：安装来源、版本、启用状态、依赖检查、权限、最近一次验证、卸载或禁用操作。
2. **发现技能**：保持五个获取来源：本地路径或直链、ClawHub、Harmony 市场、Anthropic 官方插件、OpenAI curated skills。来源选择不再与已安装列表混排。
3. **诊断与调用**：显示 Skill 的四段状态：`已安装`、`已启用`、`依赖可用`、`运行时已验证`。失败状态必须给出具体修复入口，例如安装 Node、配置密钥或重新同步磁盘目录。

安装流程保持“兼容性检查 → 安装 → 扫描目录 → 启用 → 运行时验证”。“已安装”不等于“可调用”；只有启用、依赖满足且验证成功的 Skill 会被暴露给 Codex 运行时。验证不执行用户业务任务，只检查 Skill 元数据可读取、依赖满足、相应 MCP 或本地工具可被发现。

### 设置与 IM 生命周期

渠道页不再把“配置”和“连接”分割到设置与会话页面。每个主渠道卡片有统一状态：`未配置`、`初始化中`、`等待用户动作`、`已就绪`、`需要修复`、`已连接`。状态更新同时写入设置页面和会话页的渠道状态。

**企业微信：**

1. 用户保存 Bot ID 与 Secret 后，应用先保存加密设置。
2. 应用检测内置或已管理的 `@wecom/cli`、Node 和凭据状态；可非交互完成的官方 CLI 初始化由应用执行。
3. 如果官方 CLI 返回必须由用户完成的授权或确认，卡片显示唯一的下一步动作和原始诊断摘要，不要求用户再到会话页点击连接。
4. 初始化成功后自动刷新企业能力清单、检查必要命令并连接网关。

**个人微信：**

1. 用户点击绑定后，应用启动 iLink 登录并展示二维码。
2. 扫码轮询成功后，加密保存 bot token、bot id 与 base URL，立即启动本地监听并连接网关。
3. 二维码过期、监听端口占用、令牌失效和网络失败均在卡片内提供重试或修复按钮。

高级集成包含飞书、钉钉、Telegram、Slack、Discord、Teams、Matrix、Webhook 与邮件。它们沿用既有配置字段，默认折叠，且不出现在普通用户的首屏配置任务中。

### 个人账户与用量

桌面端新增 `Account` 页面，由头像菜单的“个人账户”入口打开。它通过 Tauri 复用门户登录会话，读取官网工作空间同一组服务：

| 门户接口 | 桌面端用途 |
| --- | --- |
| `/api/gateway/balance` | 可用积分余额 |
| `/api/gateway/usage` | 今日消耗、调用次数、Token 统计 |
| `/api/gateway/credentials` | 已创建的个人 Harmony API Key |
| 既有 `/api/auth/me` | 姓名、邮箱、审批状态、头像与角色 |

Rust 命令将三个网关结果规整为一个 `AccountOverview`。页面加载时并发读取，任一非关键统计失败不会遮蔽身份或其他已成功数据。API Key 默认掩码，只在用户明确点击查看后短暂显示；复制操作不写入日志。账户页还显示云端配置快照、默认模型和“将 Harmony 凭据用于本机”的明确操作。该操作必须由用户确认，且只写入当前用户的桌面设置。

桌面 WebView 不直连网关，也不读取门户服务端的中转站管理员凭据。门户已完成员工账号与网关账号映射，桌面端只调用已认证门户接口。

### 素材库

素材库仍以门户与 NAS 索引为权威来源，桌面端不重新扫描 Jellyfin 目录。门户资产接口新增或补齐 `contentClass` 与 `isAuxiliary` 语义；桌面筛选只消费该语义，不以文件名猜测替代服务器规则。

默认查询条件为 `isAuxiliary=false`，业务文件按以下组呈现：

| 格式组 | 默认可见格式 |
| --- | --- |
| 图片 | JPG、JPEG、PNG、WEBP、GIF、TIFF、SVG |
| 视频 | MP4、MOV、M4V、MKV、WEBM、AVI |
| 音频 | MP3、WAV、M4A、AAC、FLAC、OGG |
| 文档 | PDF、DOCX、XLSX、PPTX、TXT、MD、CSV |
| 工程源文件 | PSD、AI、AEP、PRPROJ、CDR、FIG；默认不选中 |

门户过滤掉 `.nfo`、媒体字幕与歌词副本、隐藏文件、`.DS_Store`、`Thumbs.db`、Jellyfin 元数据目录，以及被索引器标识为封面、海报、缩略图或背景图的辅助记录。若业务团队确实需要某类封面，管理员应将其标记为正式业务素材，而非依赖文件名绕过过滤。

预览规则：图片使用缩放预览；视频使用带封面的播放器；音频使用波形或原生播放器；PDF 通过现有安全预览通道展示；Office 和工程源文件显示元数据、下载与放入会话操作。预览失败必须保留可见的错误状态和“保存到工作区”操作，不能显示空白面板。

## 数据流与错误处理

1. 页面切换只改变前端路由状态；后台服务与已打开会话保持存活。
2. 设置保存先持久化，再驱动 IM 初始化；初始化结果通过统一事件刷新渠道状态。
3. Skill 安装和验证串行地更新同一条 Skill 记录，避免列表显示“安装成功”但 Agent 未读取到目录。
4. 账户概览由门户授权控制。401 或 403 清除过期桌面会话并显示登录入口；统计接口暂时不可用时单独显示重试，不伪造零余额。
5. 素材库的筛选、分页与预览请求取消过期响应；选中项不在新筛选结果中时清空详情面板。

## 验收标准

1. 市场页面没有专家、成员或团队标签；五类 Skill 来源均能到达，已安装项能显示并验证可调用状态。
2. 左侧协作组包含团队、成员、专家、定时任务和记忆；工具、日志与调试只通过设置 section 进入。
3. 企业微信保存凭据后自动执行可完成的初始化、诊断与网关连接；个人微信扫码成功后无需切到会话页再次连接。
4. 个人账户页显示来自门户的身份、积分、用量、Token 与掩码 API Key；无会话或接口失败有明确恢复状态。
5. 素材库默认不显示 Jellyfin 辅助文件；格式筛选、分页和每类预览均可用；预览失败仍可保存或放入会话。
6. 所有新前端状态有单元测试；Tauri 数据规整和过滤规则有 Rust 单元测试；门户资产分类与账户接口有服务端测试；Windows `npm test`、`npm run build`、Tauri 打包和完整安装器构建通过。

## 发布与兼容性

桌面版本号提升为 `1.0.0`，产品安装器保持 Harmony Work 品牌。保留 `com.harmony.xiaoheng-workbuddy` 标识、已有本地设置路径、已安装 Skills 与 IM 凭据迁移逻辑，避免正式版升级丢失用户配置。门户资产分类字段以向后兼容的可选字段加入；旧服务器响应时客户端仍以安全的常用格式白名单显示内容。
