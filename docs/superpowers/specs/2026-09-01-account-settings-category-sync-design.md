# 账号云端配置：类别级手动同步设计

## 目标

在不降低现有端到端加密保护的前提下，为已登录且已获批准的线上营销工作台账号提供“我的云端配置”入口。用户可以查看可同步的配置类别，选择类别后手动上传或恢复配置。

第一版必须满足：

- 云端服务不接收、不解析、不记录任何配置明文或登录口令。
- 用户可以明确选择上传或恢复的配置类别。
- 未选择的云端类别不被上传操作覆盖；未选择的本机类别不被恢复操作修改。
- 工作区、渠道凭据和运行环境等设备绑定信息始终留在本机。
- 已有的全量加密快照可以无损迁移，不要求用户重新登录或清空云端数据。

## 非目标

- 不支持单字段级同步。
- 不保留多个历史版本或提供版本回滚。
- 不改变营销工作台账号、授权或审批逻辑。
- 不将本机路径、IM 渠道密钥、MCP/SSH 连接信息同步到云端。

## 方案选择

采用单一端到端加密快照、客户端类别级合并方案。

服务端继续只提供加密快照的元数据、读取、写入、删除和乐观并发控制。类别划分、选择状态、配置合并和密钥脱敏都在桌面客户端完成。

相对“每类别独立云端记录”，该方案不增加服务端数据模型和并发语义，能够复用现有 `revision` 冲突控制，也避免云端从记录数量、类别名称推断用户配置结构。

## 数据模型

加密前的载荷从现有的版本 1：

```json
{
  "version": 1,
  "settings": { "...": "..." }
}
```

演进为版本 2：

```json
{
  "version": 2,
  "categories": {
    "aiProvider": { "...": "..." },
    "vision": { "...": "..." },
    "agent": { "...": "..." },
    "toolPreferences": { "...": "..." },
    "interactionSafety": { "...": "..." }
  }
}
```

类别定义由 Rust 中的静态清单维护。每项包含稳定 ID、展示名称、说明、允许的顶层设置键和是否包含敏感值。API Key 不在 UI 中显示其值，仅显示“已配置”状态；其密文仍包含在端到端加密载荷内。

类别如下：

| ID | 名称 | 包含内容 |
| --- | --- | --- |
| `aiProvider` | AI 提供商与模型 | 默认提供商、默认模型、API Key、命名提供商、可用/启用模型 |
| `vision` | 视觉与多模态 | 视觉提供商、模型、API Key、Base URL、主模型复用开关 |
| `agent` | 智能体偏好 | 上下文窗口、迭代上限、压缩策略、个人提示词、流式输出、摘要偏好 |
| `toolPreferences` | 工具与技能偏好 | 内置工具开关、技能演进设置、通用工具行为偏好 |
| `interactionSafety` | 安全与交互偏好 | Shell/文件写入确认、语言、界面与交互偏好 |

以下设置继续由 `CLOUD_EXCLUDED_SETTING_KEYS` 强制排除，并在 UI 中显示为“仅本机”：工作区与外部文件访问控制、所有 IM 和邮件渠道凭据、MCP、SSH、用户工具自定义连接、运行时路径、本机窗口/覆盖层位置及本机加密路径。

## 客户端命令

在现有 `account_settings_sync` 命令模块中增加：

- `account_settings_sync_catalog`：返回类别清单、本机各类别摘要、云端快照元数据、可用的本机密钥状态。
- `account_settings_sync_preview`：读取并解密云端快照，返回每个类别的存在状态、字段摘要和与本机的差异计数；不返回敏感值。
- `account_settings_sync_backup_selected`：接收类别 ID 列表。客户端先读取并解密云端快照，再将本机所选类别合并进去，使用现有 revision 写回。
- `account_settings_sync_restore_selected`：接收类别 ID 列表。客户端读取并解密云端快照，仅将所选类别合并到本机设置并保存。

现有 `backup` 和 `restore` 保持兼容：前者按全部可同步类别执行，后者恢复全部可同步类别。设置保存后的自动备份也继续使用“全部可同步类别”，但不替代用户的显式手动操作。

## 迁移和冲突处理

读取版本 1 载荷时，客户端以当前类别清单将旧的 `settings` 切分为版本 2 的 `categories`。首次手动上传所选类别时写回版本 2，未选类别也会从旧快照迁移保留。

写入携带已读取的 revision。若服务端返回 `409`，客户端不静默重试或覆盖：提示用户“云端配置已在其他设备更新”，提供“重新读取”后再次选择的操作。

如果本机尚未拥有数据密钥，提示用户重新登录并完成首次同步选择；不要求再次输入密码，也不缓存明文口令。

## 设置页交互

在现有设置页面添加“我的云端配置”区块：

1. 显示登录状态、最近同步时间和来源设备；未登录时提供登录入口。
2. “查看云端配置”打开模态窗口。
3. 模态窗口内每个类别使用复选框、名称、说明、配置摘要和可展开的字段名称列表。
4. 支持“全选”“取消全选”，默认不选中，避免误覆盖。
5. “上传所选配置”与“恢复所选配置”在无选择时禁用。恢复前展示二次确认，说明仅会修改勾选项。
6. 在底部固定显示“仅本机配置”提示，明确工作区、渠道、MCP/SSH 和运行环境不会被同步。

视觉遵循现有设置页的卡片、按钮、表单和动画风格；不引入新的一级导航或独立页面。

## 错误处理

- 未登录、未获批准：禁用云端操作，保留说明和登录入口。
- 无快照：恢复按钮禁用并说明“尚无云端配置”；上传仍可用。
- 解密失败：提示重新登录或确认账号密码是否已修改，不展示或覆盖本机配置。
- 网络失败：保留当前选择，不修改本机设置，展示可重试错误。
- 字段不兼容：跳过未知键，记录可诊断日志，继续处理其他兼容类别。

## 测试

- Rust 单元测试：类别清单字段边界、敏感字段摘要脱敏、选择上传合并、选择恢复合并、版本 1 到 2 迁移、未选类别保持不变、设备绑定设置不进入任何类别。
- 命令测试：空选择拒绝、无本机密钥拒绝、409 冲突不覆盖、解密失败不写入本机。
- 前端测试：未登录/无快照/有快照状态、选择与全选行为、上传/恢复请求参数、恢复确认和错误呈现。
- 回归测试：现有全量自动备份、初次登录恢复提示和服务器加密信封接口保持可用。

## 验收标准

- 用户可在设置中打开“我的云端配置”，看见类别和不可同步项目说明。
- 用户选择任意子集后，上传只改变云端对应类别；恢复只改变本机对应类别。
- API Key 等敏感值在 UI 任何位置都不以明文出现。
- 服务端数据库仍只保存加密信封，且不增加明文配置列。
- 旧版本 1 快照可以在新版本客户端读取并在首次手动同步后迁移。
