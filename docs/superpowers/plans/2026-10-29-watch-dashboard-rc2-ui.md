# 腕表如诗内容看板 RC2 体验优化

版本：1.1.4-rc2。仅客户端 UI、交互及版本元数据；不修改服务端接口、存储、登录和媒体权限，不覆盖 RC1 发布记录。

## 实现

- 视频卡片使用错峰入场与封面骨架，保留固定卡片尺寸，尊重减少动态效果设置。
- 视频完整档案与共享档案统一为 document.body 顶层原生 dialog：大尺寸毛玻璃面板、内部滚动、固定关闭栏、Esc/遮罩关闭、焦点恢复与关闭动效。
- 共享档案卡片展示品牌、系列、型号、材质/表盘/尺寸、描述、标签、核验状态及来源数量；无数据不捏造规格。
- 检索展示排队、服务端处理与结果阶段；只有真实 total/done 才呈现可计量进度。重新发起请求时清理旧结果。
- 上传窗口展示来源、完成/进行中/失败统计、校验/传输/保存入库阶段；传输 100% 不冒充已入库，校验中仍可暂停或取消。
- 保持键盘可用、浅深色、390/760/1440 布局及减少透明度的实色回退。

## 验证及交付边界

- 68 个前端测试文件、415 项测试通过；Node 合同测试 38 项通过，build:web 通过。
- 真组件 Playwright 夹具验证两个档案入口、弹层尺寸/内部滚动、Esc、遮罩、关闭焦点恢复，浅深色三尺寸通过。截图是示例数据，不代表生产服务端验收。
- 版本元数据更新为 RC2。用户后续授权推送后，Windows 轻量包已构建、签名、校验并推送测试通道；正式版仍为 1.1.3，Mac 通道不变。最终包及发布证据见 `docs/releases/windows-1.1.4-rc2.md`。
