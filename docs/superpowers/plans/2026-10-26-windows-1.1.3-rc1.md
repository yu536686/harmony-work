### 新能力（必须可用，不能占位）

- 任务中心：聚合现有会话、Harvis、IM、定时任务；状态/进度/来源/错误/成果，跳回来源；查询重试不得重新发起付费生成。重启恢复依赖真实持久化数据。
- 文件变更审阅：本轮新增/修改列表、文本差异和可恢复版本；恢复前检测磁盘是否再次变化，用户确认后执行，不回滚邮件/云端外发等副作用。复用现有 journal，新增快照受工作区及大小限制。
- 诊断与修复：Node/Python/WeCom/浏览器/MCP 的真实健康检查，明确网络/模型协议错误；提供离线修复入口和脱敏诊断导出，不输出 Key/Token。
- 用量与预算：会话/项目已知 Token 及可设置限额，缺价格时不捏造费用；超过用户阈值阻止新提交或明确确认。重试不能重复提交原生成。
- 交付流程模板：保存可复用提示词、技能和交付要求；从模板启动正常对话，仍走既有权限/模型/任务机制。模板不能包含账户密钥；可编辑、删除、跨重启保存。
- Windows 界面：系统字体、DPI/文字缩放、键盘与焦点、长路径/文件名、窄窗口和长列表；已有 980px 最小宽度保持。共享 CSS 使用 Windows 作用域，Mac 原生 UI 不重制。
