# Windows 1.1.3-rc2 导航体验修复

基线：`a02d253` / Windows 1.1.3-rc1。分支：`feat/windows-1.1.3-rc2`。

## 需求与范围

- [x] 定位顶部菜单滚轮不带动侧栏的问题：Windows `.sidebar-nav` 的 `overflow-y:auto` 与 `overscroll-behavior:contain` 形成不可滚动但阻止链式滚动的内层容器。
- [x] 移除内层滚动覆盖，保持 `.sidebar-body` 统一滚动；不添加拦截滚轮的脚本。
- [x] 协作、系统、项目采用与 AI 创作一致的图标、字号、行高和折叠箭头；搜索按钮占满侧栏可用宽度。
- [x] 移除底部极简模式入口，保留已有窗口后端能力，避免破坏 IM 等依赖。
- [x] 菜单和项目内容使用高度/透明度过渡；收起内容立即不可访问、不可聚焦。搜索入场动画不延迟卸载，不保留关闭后的账户结果。
- [x] 全部前端回归、真实 Chromium 鼠标滚轮与布局交互验收，兼容减少动态效果；Windows 原生回归通过。
- [x] 版本统一为 1.1.3-rc2；Windows release 构建、轻量包签名和隔离账户升级验收。
- [x] COS/CDN 完整回下载校验后只切换 Windows preview，stable、官网正式下载和 Mac 资源不变。
- 分支交付：`feat/windows-1.1.3-rc2`；不自动合并 main。

冻结运行时保持原载荷和哈希；已知离线 Python 缓存兼容白名单须明确包含 rc2，不放宽校验。构建和私有验证产物放入忽略的 `release/verification/`。不得停止或升级 Admin 正在使用的客户端。

## 初步验证

新增导航回归先失败后通过；全局会话树及搜索定向共 16 项、前端全量 394 项及 38 项 Node 契约通过。真实 Chromium 鼠标滚轮在 RC1 样式复现失败，RC2 样式成功滚动；覆盖 980px、1440px、搜索重开清空、收起项不可聚焦及减少动态效果。

独立审查指出的侧栏收起后按钮无障碍展开状态不一致已修复并添加回归。Windows 原生 381 项通过、2 项需生产离线载荷而忽略（已在单独的载荷测试中验证），MCP 主机 41 项通过；配置 DPAPI 安全快照及恢复通过。生产可执行文件仍在构建，尚未开始发布。

Windows 构建辅助脚本遇到 PowerShell 5 锁文件同名大小写键与跟踪的离线安装器预检问题，已分别改用 Node 深度比对锁文件及对跟踪文件做清单和哈希比对；旧预检目录保留在 `E:\harmony-work-113-rc2-preflight`，不影响用户客户端。
