# Windows 1.1.3-rc1 候选验收

## 范围

已发布到 Windows preview 测试通道，不自动合并 main，不替换官网正式 Windows 下载、Mac 安装包或 Mac 更新配置。版本统一为 `1.1.3-rc1`，仅供兼容已有完整安装的测试用户升级。

- 任务中心汇集本地会话、IM、定时任务及当前账户的 Harvis 任务，支持状态筛选、进度、错误和成果跳转。未经账户归属验证的手机记录不进入新聚合入口。
- 工具面板增加文件变更审阅与用量限额；恢复前确认并检查后续磁盘修改，不能撤销邮件或云端外发等副作用。快照受文件数量、大小及轮次上限约束，捕获失败明确提示而不伪装成“无变更”。
- 交付流程模板保存提示词、技能及交付要求，启动正常会话草稿，不自动发送。全局搜索读取本地会话、项目、成果及设置，不调用模型。
- 修复启动停止竞态、前后台权限范围、附件历史、成果关联、Harvis 查询乱序、账户缓存及离线退出、设置保存和秘密字段落盘；强化外部打开、技能安装及 HTML 预览边界。
- HTML 默认静态隔离；可信内容须明确启用交互和联网。工作区外同目录资源为独立授权，不因“允许联网”自动开放。
- Harvis 历史按账户绑定；无法确认归属的旧缓存保留在磁盘，但不自动归入当前登录账户或展示给其他账户。
- Windows 保持 980px 最小宽度，改善字体、焦点、长路径、缩放与高对比度；不重制 Mac 原生界面。

## 兼容与恢复

轻量包仅覆盖 18 个自有文件，复用 189 个资源，严格验证嵌入式 Python 1678 条或标准 Python 6057 条运行时哈希。不升级 Codex、Playwright、FlaUI、Node、Python、Git 或 WeCom 的冻结载荷；不兼容时拒绝覆盖，不能用于首次安装。

配置回滚快照使用当前用户 DPAPI，不保留明文备份。应用启动须返回匹配版本与随机 token 的前端健康确认，再持续运行 15 秒才提交；失败恢复原文件与配置。数据库与工作区不做事务回退。

离线 Python 修复可复用明确兼容旧版的完整缓存，但旧包声明和真实 ZIP 必须匹配固定 SHA-256。缺少缓存时提示使用完整离线安装包，不偷偷联网下载或删除用户工作区。
