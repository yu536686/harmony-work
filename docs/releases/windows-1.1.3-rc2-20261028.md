# Windows 1.1.3-rc2 测试版

本版仅发布到 Windows preview 通道，基于 1.1.3-rc1。正式通道仍为 1.1.2；官网正式下载、Mac 安装包和更新清单未改动。

## 修改

- 修复鼠标位于左侧顶部菜单时滚轮无法滚动整个侧栏：移除阻止滚动传递的内层滚动容器。
- 统一协作、系统和项目入口的图标、字体、行高及展开样式；项目和系统支持折叠，保留新建项目入口和项目状态。
- 搜索按钮适配侧栏可用宽度；移除底部极简模式按钮，保留已有窗口能力供其他功能使用。
- 菜单、项目和搜索弹窗增加过渡；收起的内容不可聚焦或被辅助功能误读，遵循系统减少动态效果设置。搜索关闭时仍立即清理数据。
- 离线 Python 修复对 RC2 显式允许复用已验证的旧版缓存，维持严格的版本和 ZIP SHA-256 双重校验。

## 测试更新

Windows 客户端打开“设置 → 关于”，勾选“接收测试版本更新”，再点击“检查更新”。等待当前任务结束，按提示安装；安装完成前不要手动再次打开客户端。

[下载 1.1.3-rc2 轻量更新包](https://download.harmonywatch.cn/releases/Harmony-Work-1.1.3-rc2-x64-light.exe)：18767702 bytes；SHA-256 `e23c1f71db55c0326d63c705c812eeaf663b4f5a1a0e89e45b3d85a94a4abd76`。轻量包不能用于首次安装，须已有兼容的完整客户端；不兼容时会拒绝覆盖。

安装日志：`%LOCALAPPDATA%\Harmony\WorkBuddy\updates\light-installer.log`。

## 验证

前端 394 项、Node 契约 38 项；Windows 原生 381 项（2 项忽略）、MCP 主机 41 项通过。真实 Chromium 鼠标滚轮在旧样式下复现、在新样式下修复，并验证 980px/1440px、搜索、折叠及减少动态效果。Windows 隔离账户实际完成 RC1 → RC2 升级及健康检查失败回滚，保留原配置、会话和工作区。签名、篡改拒绝及 CDN 全量回下载哈希通过。

上述结果不等同于全部 Windows 设备和业务场景的人工验收；如自动更新失败，请保留安装日志用于排查。执行记录见 [计划与账本](../superpowers/plans/2026-10-28-windows-1.1.3-rc2.md)。
